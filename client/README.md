# See [demo](https://egas099.github.io/points/)

## Scripts

In the `client` directory:

### `npm start`

Runs the app with Vite. Opens [http://localhost:3000/points/](http://localhost:3000/points/).

### `npm test`

Starts Vitest in watch mode.

### `npm run build`

Type-checks and builds the production bundle into `dist`.

### `npm run preview`

Serves the production build locally.
